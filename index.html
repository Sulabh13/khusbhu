about me

The developer behind the code

AR

I'm a frontend developer with 4+ years of experience building fast, accessible, and visually considered web applications. My work centers on HTML, CSS, and modern JavaScript (ES6+), with React as my framework of choice for building maintainable, component-driven interfaces.

Alongside frontend work, I use Python to build the supporting layer — small APIs, automation scripts, and data-processing tools that connect a polished UI to real, working systems. That combination means I can take a project from a Figma file to a fully functioning product, not just the parts that render in a browser.

What sets me apart isn't a single skill — it's the habit of treating performance, accessibility, and clean code as defaults, not afterthoughts. I care about the 200ms it takes a button to respond as much as the pixel it sits on.
